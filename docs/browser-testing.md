# Браузерные проверки Clio

Запуск из папки Clio:

```powershell
npm.cmd run test:e2e
```

Скрипт использует установленный Chrome из стандартной папки Windows. Обычный профиль браузера и его пароли не используются. На компьютере без такого Chrome можно предварительно выполнить `npx.cmd playwright install chromium`; это бесплатная загрузка тестового браузера. Версия `@playwright/test` закреплена в package-lock.json.

## Что происходит

1. Настройки читаются из `.env.local` без вывода секретов.
2. Создаётся уникальная схема `clio_e2e_<uuid>` в PostgreSQL и разворачиваются все миграции. Фикстуры дополнительно проверяют `current_schema()` перед записью.
3. Настоящий Next.js запускается на свободном локальном порту, с отдельным каталогом сборки `.next-e2e`. Основной сайт на порту 3000 продолжает работать.
4. Для каждого независимого сценария создаются отдельные аккаунты с временными случайными паролями, включая тестового администратора и обычных пользователей. Это данные только временной схемы. В браузере проверяется обычный вход по паролю, серверная авторизация не подменяется.
5. Каталог и изображения загружаются из настоящего TMDB. Используются реальные формы, Server Actions и PostgreSQL. В отдельном случае браузер намеренно получает один ответ 502 для постера, чтобы проверить автоматическую повторную загрузку; остальные ответы настоящие. В тестовом экземпляре SMTP направлен на локальный неработающий адрес: отправки по настоящим email отсутствуют. Поэтому проверка доставки писем не входит в этот набор.
6. После завершения останавливается только запущенный тестовый сервер и удаляется только созданная им схема. Основные аккаунты и пользовательские данные не изменяются.

Независимые сценарии сбрасывают ограничитель запросов только во временной схеме, поскольку все браузерные контексты приходят с localhost. Производственные лимиты и настройки приложения не ослабляются.

## Сценарии

- Два пользователя: вход, галочка, доступ к панели, библиотека, независимость данных, оценки и история, просмотры, рецензии со спойлерами, закрытая/дружеская видимость, дружба, комментарии/ответы/лайки, уведомления, коллекции и порядок, статистика, модерация, исправления каталога, отключение уведомлений и удаления.
- Общий каталог: фильтры года/жанра/страны/рейтинга, каждый постер страницы, фильмы/сериалы, поиск людей и фильмография, аниме, клиентская проверка несовпадающих паролей.
- Аккаунт: завершение других сессий, смена пароля, вход с новым паролем, username и удаление отдельного тестового аккаунта.
- Мобильный экран Chromium: отсутствие горизонтального переполнения, три темы, RU/EN/DE, обновление PWA с отменой/подтверждением, сохранение черновика до подтверждения, только публичные файлы в офлайн-кэше и офлайн-страница.

После упрощения интерфейса сценарии используют шестерёнку настроек, разделы `/settings`, вкладку друзей и нижние панели. Мобильный сценарий проверяет пять пунктов навигации и активный пункт на вложенных экранах, отсутствие открытых редакторов на профиле/карточке и закрытие панели через Escape с возвратом фокуса. Скриншоты сохраняются в размере экрана телефона. Редактирование рецензии проверяется также по ссылке из меню.

Отдельный запуск:

```powershell
npm.cmd run test:e2e -- --project=mobile
npm.cmd run test:e2e -- --project=desktop
```

HTML-отчёт находится в `playwright-report/index.html`, скриншоты и трассы ошибок — в `test-results/`, лог тестового сервера — в `.e2e-output/server.log`. Они исключены из Git. Трассы могут содержать временные тестовые пароли; публиковать их не нужно. Новый запуск заменяет предыдущий отчёт и `test-results`.

## Границы проверки

Мобильный Chromium эмулирует экран и сенсорное устройство; он не заменяет настоящий Safari на iPhone. Установка приложения через ОС, доставка email/смена email через почтовые ящики, публичный HTTPS-хостинг и работа из разных российских сетей без VPN требуют отдельных проверок. Регистрация, подтверждение и сброс пароля дополнительно проверяются интеграционным тестом с почтовым перехватчиком в изолированной схеме.

Остальной набор проверок: `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test`, `npm.cmd run test:db`, `npm.cmd run build`.
