## Исправлено

1. Первая активация service worker перезагружала страницу и могла очистить начатый ввод. Теперь перезагрузка выполняется только после подтверждённого пользователем обновления.
2. PostgreSQL возвращал дату просмотра объектом Date, тогда как интерфейс дневника ожидал строку. Дата явно форматируется в `YYYY-MM-DD` на стороне SQL и корректна для отображения и редактирования.
3. После удаления коллекции обновление страницы могло размонтировать форму до клиентского перехода, оставляя 404 на старом адресе. Переход теперь выполняет сервер после успешной транзакции. Удаление рецензии возвращает к карточке произведения.
4. Поле жанра могло перекрывать соседний фильтр; длинное имя и немецкие элементы шапки выходили за ширину телефона. Исправлены минимальная ширина контролов и переносы.
5. При одном из прогонов TMDB не успел отдать постер за сетевой тайм-аут. Добавлены две ограниченные повторные попытки с паузой; бесконечного повторения нет. Сетевой отказ проверяется отдельным браузерным случаем.

Код исправлений: `src/components/pwa-controls.tsx`, `src/app/diary/page.tsx`, `src/modules/social/actions.ts`, `src/modules/library/mutations.ts`, `src/modules/catalog/poster.tsx`, `src/app/globals.css`.

Проверки и настройка: `e2e/desktop.spec.ts`, `e2e/mobile.spec.ts`, `e2e/fixtures.ts`, `scripts/run-e2e.mjs`, `playwright.config.ts`, package.json/package-lock.json. Каталоги тестовой сборки и отчётов исключены из Git и ESLint; Next.js добавил типы тестовой сборки в tsconfig.json.

## Границы

Это проверка локального приложения, не обещание отсутствия всех ошибок и не аудит безопасности перед публикацией. Настоящий Safari/iOS, Android и установка через ОС не проверены. Доставка письма в реальный почтовый ящик и смена email через оба ящика в браузерный набор не входят; регистрация/подтверждение/сброс пароля проверяются отдельно в интеграционном тесте с почтовым перехватчиком.

14 ноября сайт опубликован на alwaysdata Free. Владелец подтвердил сайт и постеры в мобильной сети РФ без VPN; другие сети не проверены. HTTPS, проверяемый TLS PostgreSQL, перенос данных и мобильный публичный Chrome проверены отдельно: [отчёт запуска](public-launch.md). Юридическая готовность сервиса и требования к персональным данным пока не подтверждены. В графе production-зависимостей аудит показал 4 moderate, 0 high/critical; затронута цепочка инструментов drizzle-kit/esbuild, которой нет в standalone. Принудительное обновление стека не выполнялось. В тестах PostgreSQL остаётся предупреждение о параллельных запросах одного Client, production использует Pool.

Инструкция повторения: [браузерные проверки](browser-testing.md). Предложение коммита: `test: add browser QA and fix discovered Clio issues`. Коммит и push автоматически не выполнялись.
