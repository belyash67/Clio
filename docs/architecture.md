# Архитектура Clio

Статус: принятые проектные решения; реализация первого этапа начата. Готовность отдельных функций отслеживается в stage-1.md.
Основание: README и поручение владельца самостоятельно выбирать решения в их рамках.

## Стек и границы

- Одно приложение Next.js App Router: React, строгий TypeScript, Tailwind CSS, Lucide.
- Серверные компоненты читают данные через серверные модули. Server Actions выполняют изменения; Route Handlers обслуживают auth и HTTP-интеграции.
- PostgreSQL, Drizzle ORM и проверяемые SQL-миграции. Better Auth с Drizzle-адаптером управляет паролями, подтверждением email и сессиями. Точные совместимые версии выбираются перед установкой.
- Модули: auth, profiles, catalog, library, reviews, collections, social, moderation, notifications.
- Проверки сессии, входных данных, владения и приватности выполняются на сервере. Скрытие элементов интерфейса не заменяет авторизацию.
- Нет отдельного API-сервера, Redis, поискового кластера или микросервисов на старте.

## Продуктовые решения

- Одна текущая оценка пользователя на произведение, от 1 до 10 с шагом 0,5. В БД — целое значение от 2 до 20, в интерфейсе делится на два.
- Просмотры и пересмотры — отдельные события. Изменения оценки сохраняются в истории; история не создаёт дополнительные голоса в рейтинге.
- Статус библиотеки необязателен; избранное независимо. Одна запись библиотеки на пользователя и произведение.
- Рецензия отделена от оценки; в первой версии одна рецензия пользователя на произведение, допускающая редактирование и отметку спойлеров.
- Профиль по умолчанию доступен подтверждённым друзьям, варианты friends/public. Принятая дружба всегда открывает профиль, даже при старом значении private или отсутствующих настройках. Библиотека и активность по умолчанию private; у публикаций отдельные ограничения. Открытый другу профиль не раскрывает личный контент.
- Поиск пользователей возвращает только публичные профили, исключает заблокированных пользователей. Email не выдаётся в публичных ответах.
- Первый публичный релиз включает дружбу, ленту, комментарии к рецензиям, лайки рецензий и внутренние уведомления. Подписки, совместные коллекции, push и комнаты отложены.
- Русский — исходный язык интерфейса; английский и немецкий должны быть завершены к первому публичному релизу. Строки с начала разработки отделяются от компонентов.
- Закрепление четырёх фильмов отложено. Загрузка аватаров и обложек отложена; сначала стандартные аватары и разрешённые изображения каталога.
- Мобильные вкладки: Главная, Каталог, Библиотека, Сообщество, Профиль. Поиск внутри каталога; коллекции в библиотеке, уведомления через отдельную кнопку, настройки в профиле.

## Данные каталога

- Идентичность произведения: уникальная пара (movie или tv, tmdb_id). Анимация и аниме — отдельные признаки, не типы TMDB. Не определять аниме только по стране; спорные случаи допускают ручную модерацию.
- Сначала поиск по названиям; фильтры, поиск по людям и жанрам добавляются до завершения каталога. Не обещать полноту локального поиска по ещё не импортированному каталогу.
- TMDB вызывается только сервером. Метаданные сохраняются в PostgreSQL, переводимые поля кэшируются отдельно по языку.
- Начальная политика: карточки 24 часа, поисковые ответы 15 минут. Запросы объединяются по ключу, ограничиваются по времени; при допустимой ошибке источника показываются ранее полученные данные с отметкой актуальности.
- Ошибки внешнего сервиса не заменяются вымышленными результатами. Кэширование и сроки хранения сверяются с условиями TMDB до реализации интеграции.
- Изображения хранятся как пути или ссылки. Доступность image.tmdb.org проверяется отдельно от API; проксирование нельзя считать заранее разрешённым или бесплатным.
- Для локальной работы при неверном DNS постеры передаются через ограниченный серверный обработчик Clio: фиксированные хост/размер, проверка сигнатуры, ограниченный временный кэш без записи бинарных данных в PostgreSQL. Перед публичным размещением условия TMDB и стоимость трафика проверяются отдельно; подробности в stage-2.md.
- Взвешенный рейтинг Clio: (v × R + m × C) / (v + m), где v — число текущих оценок, R — их среднее, C — среднее по Clio, m = 10 на старте. При отсутствии всех оценок рейтинг не показывается. Выводятся и количество оценок, и обычное среднее; сортировка использует взвешенное значение.

## Безопасность и приватность

- Secure/HttpOnly cookie в production, HTTPS, защита межсайтовых запросов средствами выбранного auth/framework и проверка origin для изменяющих операций.
- Неподтверждённый аккаунт не публикует контент и не отправляет дружеские запросы. Ограничения частоты регистрации, входа, писем и публикаций проектируются для нескольких процессов, без зависимости от памяти одного сервера.
- Роль администратора назначается только доверенной серверной процедурой. Первоначальный администратор создаётся отдельно, не через параметры регистрации.
- События ленты содержат ссылки на объекты; права на объект проверяются при чтении заново. Уведомления не содержат закрытого текста в обход прав.
- Автор видит своё; посторонний — только явно разрешённое. Для друзей дополнительно требуется принятое отношение. Видимость контента ограничивается также видимостью профиля.
- Для открытой регистрации обязательны жалобы, блокировка аккаунтов, скрытие контента и журнал действий модератора.
- После выхода приватные клиентские данные очищаются. Service worker не кэширует auth, личные страницы и пользовательские API-ответы.
- Резервные копии и восстановление проверяются до публичного запуска. Проверка требований к персональным данным — отдельное условие запуска, соответствие пока не установлено.


## Размещение и стоимость

Локальная разработка: PostgreSQL на компьютере, приложение на localhost. Публичная версия с 14 ноября 2026: alwaysdata Free, Node.js 24, PostgreSQL 18, HTTPS и проверяемое TLS-подключение к БД. Серверный пакет Next.js standalone собирается локально из-за лимита памяти хостинга; отдельные Linux-модули изображений добавляются при упаковке. Публичный сайт и локальная БД теперь независимы. Устройство и границы проверки: [публичный запуск](public-launch.md).

Перед публикацией проверить лимиты, остановку неактивных ресурсов, исходящий трафик, резервные копии, SMTP, размещение данных, отсутствие автосписаний и совместимость с серверным Next.js. Для замены провайдера достаточно переноса PostgreSQL, переменных окружения и адаптеров внешних сервисов.

Проверка из РФ: минимум домашняя и мобильная сети без VPN; сайт, регистрация, доставка письма, вход, поиск, постеры и сохранение библиотеки. Пока таких проверок не было. Если подходящего бесплатного решения нет, публичный запуск откладывается и обсуждается с владельцем; платный тариф автоматически не подключается.
