# Завершение локальной версии Clio

Владелец разрешил реализовать оставшиеся функции сайта одной задачей, а затем поручил агенту самостоятельную браузерную проверку и явно разрешил Playwright. Автоматические проверки остаются обязательными. Это разрешение включает переходы между перечисленными блоками; не включает публикацию, push, платные услуги или изменение системных настроек. Итог последующей проверки и исправления: [отчёт QA](qa-report.md).

Порядок: схема и серверные политики → библиотека/оценки/просмотры → рецензии и коллекции → дружба/лента/уведомления → статистика/рекомендации → настройки/модерация → PWA и проверки.

Новые связи: users и media → library, watch_history, ratings, rating_events, reviews; reviews → comments/review_likes; users → collections → collection_media → media; users ↔ friendships; users → notifications/reports; admin → moderation_actions. Для каждой связи — FK, для пар — уникальность; личные данные удаляются вместе с аккаунтом. Оценки и рецензии независимы. Лента строится по текущим записям с повторной проверкой видимости, не копирует приватный текст.

Профиль: friends/public, всегда доступен подтверждённым друзьям; библиотека, активность и рецензии: private/friends/public; коллекции: private/public. Видимость контента дополнительно ограничивается профилем. Поиск пользователей — только по публичным профилям. Рейтинг Clio агрегируется анонимно и не раскрывает частные оценки. Комментарии и лайки разрешены только для доступной рецензии. Заблокированный аккаунт не создаёт сессии и не выполняет закрытые операции.

Не входят в первую версию: загрузка аватаров/обложек (ранее отложена), комнаты, push, Wrapped, прогресс эпизодов. Системные аватары остаются стандартными. Переводы интерфейса и PWA требуют отдельных проверок; готовность не объявляется по одному наличию файлов.

Критерии: реальные операции в PostgreSQL, отсутствие доступа к чужим закрытым данным, проверки двух пользователей/миграций, lint/typecheck/tests/build. Живые браузерные сценарии выполняет владелец. Нерешённые инфраструктурные и лицензионные вопросы публичного запуска отражаются в документации.

## Автоматическая проверка

Проверки выполняются локально: ESLint, TypeScript, 18 обычных тестов, 4 интеграционных сценария на PostgreSQL и production build. Интеграционные тесты разворачивают все миграции в собственных схемах и проверяют auth, ограничитель запросов, каталог, владение данными, приватность, дружбу, оценки, просмотры, комментарии, коллекции, модерацию и загрузчики новых страниц. SMTP перехватывается только изолированным тестом; это не проверка реальной доставки писем.

В тестовом сценарии встречается предупреждение pg о параллельных запросах одного Client; текущие проверки проходят, production использует Pool. Это нужно учесть перед переходом на будущую pg 9. Последующая проверка интерфейса через Playwright выполнена агентом; реальные устройства и внешние сети требуют отдельной проверки: [отчёт QA](qa-report.md), [чек-лист](live-checklist.md).

После итоговой сборки dev-сервер запущен на localhost:3000. HTTP-проверки главной, каталога с фильтрами и входа вернули 200; `/admin` без сессии — перенаправление 307 на вход. Manifest, service worker и PNG-иконка отдаются с ожидаемыми типами. Это техническая проверка ответов, без замены ручной проверки интерфейса. `db:generate` подтвердил отсутствие расхождений схемы и миграций.

## До публичного запуска

Нужно выбрать и проверить бесплатное размещение приложения и PostgreSQL без карты, HTTPS, резервное копирование и восстановление, доставку почты, реальные устройства PWA и доступность из сетей РФ без VPN. Нужны актуальная проверка условий TMDB, официальный логотип/атрибуция и допустимость доставки постеров через сервер, а также требования к персональным данным. Известные предупреждения аудита зависимостей требуют отдельной оценки перед публикацией; автоматическое обновление стека без проверки не выполнялось.

Жанры и титры хранятся в кэше TMDB, идентификаторы жанров — также в media; отдельные нормализованные people/genres сейчас не создаются. Лента вычисляется из разрешённых записей, без отдельной копии закрытого контента. Рекомендации ограничены произведениями, уже попавшими в локальный каталог; это простое жанровое правило, без внешнего AI и платных услуг. Переводы интерфейса проверены по помеченным статическим строкам; редкие ошибки и тексты сторонних источников требуют живой языковой проверки. Полноценный офлайн-доступ к пользовательским данным не реализован.

Push, публикация, загрузка файлов, комнаты и остальные отложенные функции не выполнялись. Предложение коммита: `feat: complete local Clio MVP and owner badge`. Коммит и push автоматически не создавались.
