# Публикация исходников

Публикуй через Git, а не загрузкой всей папки или ZIP с компьютера. Исключение в `.gitignore` действует на Git; оно не убирает секреты из вручную созданного архива и не отключает OneDrive.

В репозиторий входят исходники, миграции структуры БД и `.env.example` с пустыми значениями/образцами. Настоящие `.env*`, `.runtime/`, локальные отчёты с личными сведениями, дампы, архивы, приватные ключи, логи и результаты браузерных проверок исключены. Эти файлы остаются локально и нужны для эксплуатации; не удаляй рабочие пароли ради публикации кода.

Перед публикацией выполни `npm.cmd run secrets:check`. Проверка читает доступные локальные секреты только для сравнения, проверяет публикуемые файлы, индекс Git и доступную локальную историю. Выводит только расположение и вид находки, без значения. Это дополнительная проверка известных секретов и характерных форматов, а не гарантия обнаружения любой конфиденциальной информации. Отдельно просмотри список файлов в VS Code Source Control перед коммитом.

Не используй `git add -f` для исключённых файлов. `.gitignore` не защищает секрет, уже попавший в коммит: такой ключ нужно отозвать/заменить, а очистку истории выполнять отдельной согласованной операцией. Проверка локальной истории не доказывает отсутствие ранее опубликованных чужих копий, веток или артефактов GitHub.

Публикуй обычную ветку проекта. Не используй `git push --mirror` и не загружай папку `.git`: в ней могут быть локальные служебные снимки `refs/codex/`, которые не относятся к публикуемой ветке и могут сохранять внутренние заметки. Исключение файла из будущих коммитов не стирает такие локальные снимки.

Публичный адрес сайта и адрес для обращений не являются ключами доступа. Имена переменных `SMTP_PASSWORD`, `BETTER_AUTH_SECRET` и `TMDB_READ_ACCESS_TOKEN` в коде оставлены: секретны их реальные значения, которые приложение получает из окружения сервера. Подключение по `DATABASE_URL` также берётся из окружения.

Публикация исходников не требует изменения рабочего хостинга и не делает базу данных публичной.
